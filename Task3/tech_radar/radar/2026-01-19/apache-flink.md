Apache Flink

Фреймворк для потоковой обработки с поддержкой состояния и точной однократной семантики (exactly-once). Обрабатывает неограниченные потоки данных с минимальной задержкой (< 100 мс). Идеален для сценариев: обнаружение мошенничества в реальном времени, мониторинг, событийная аналитика. Поддерживает пакетную обработку через Table API и интеграцию с Kafka, Pulsar.
