Polars

Polars — высокопроизводительная библиотека для работы с датафреймами, написанная на Rust и предоставляющая API для Python и Rust. Сочетает скорость колоночных движков с удобным синтаксисом, привычным для специалистов по данным. Оптимизирована для работы с большими объёмами данных, превосходя Pandas по производительности во многих сценариях. Активно используется в задачах исследовательского анализа и лёгкой ETL-обработки .
